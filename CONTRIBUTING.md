# Contributing

Thanks for helping improve **School Fee Management System**!

1. Fork the repo and create a branch: `git checkout -b feat/my-feature`
2. Follow PSR-12 (`./vendor/bin/pint`)
3. Add or update tests (`php artisan test`)
4. Use Conventional Commits (`feat:`, `fix:`, `docs:` …)
5. Open a pull request using the template

**Never commit real Razorpay keys or `.env` files.**
